# Argos

Analizador local de ficheros sospechosos: le das un fichero y devuelve un informe con qué es, qué contiene y qué hace al ejecutarse en una máquina virtual desechable. Por defecto no envía nada fuera del equipo. No es un antivirus: no bloquea nada.

Proyecto del bloque 1 de Proyectos de Ciberseguridad (U-tad, 4.º, curso 2026-27). Trabajo individual de Rodrigo Martínez Hernández.
